# sync-engine

A sync engine for the browser and Node.

## Setup

Requires Node 24 and pnpm 12.

```sh
nvm use
pnpm install
```

## Scripts

| Script           | What it does                  |
| ---------------- | ----------------------------- |
| `pnpm test`      | Run tests                     |
| `pnpm typecheck` | Type check                    |
| `pnpm build`     | Build to `dist/`              |
| `pnpm lint`      | Lint (`lint:fix` to fix)      |
| `pnpm fmt`       | Format (`fmt:check` to check) |
